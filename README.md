# teb-mpc-local-planner

Simulation-only comparison of a timed-elastic-band (TEB) style optimizer and a linearized OSQP MPC local planner for a differential-drive robot, across scripted static and moving-obstacle scenarios, with a browser demo. Not the ROS teb_local_planner and not a Nav2 plugin. See PLAN.md.
